# marketplace

Claude Code 및 Codex 플러그인 마켓플레이스입니다.

- [gpt-workspace](plugins/gpt-workspace/README.md): Codex에서 **Make Workspace** 스킬로
  지정한 기반 브랜치의 작업 브랜치와 프로젝트별 `.worktrees` 작업 공간을 생성합니다.
- [gpt-java-formatter](plugins/gpt-java-formatter/README.md): Codex에서 Java 파일을
  기존 Eclipse 스타일로 포맷팅하는 스킬과 파일 편집 후 자동 포맷팅 훅입니다.
- [gpt-review-toolkit](plugins/gpt-review-toolkit/README.md): Codex 작업 종료 시 변경 파일을
  주석 정확성·사용자 의도 반영·테스트 충분성·성능 분야의 서브에이전트로 리뷰하고 중요도순으로 보고합니다.
